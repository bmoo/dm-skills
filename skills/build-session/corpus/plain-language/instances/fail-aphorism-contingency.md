# Instance — fail · aphoristic compression in a contingency

## The line (run-time text — a contingency)

> **If the negotiation sours:** when the tide turns, spend the candle — but never let
> them see the wick.

## What the page defines nearby

- None of these figures is defined anywhere on the page: "when the tide turns", "spend
  the candle", "let them see the wick" are **aphoristic compression** — design-voice
  metaphor dropped into text the DM must execute at the table. There is no mechanic and
  no page-defined referent for any of them. A stranger DM at 9pm mid-scene cannot act
  on this line. Aphorism belongs in design discussion, never in run-time text — the
  `plain-language` defect.
