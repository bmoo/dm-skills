# Instance — edge · coinage a competent DM resolves from the line itself

## The line (run-time text — a contingency)

> **If they search the abbot's cell:** they find his **breath-book** — a slim journal of
> confessions he recorded in a whisper-code of dots — and a DC 14 Investigation check
> deciphers the last entry.

## What the page defines nearby

- **"Breath-book" is coined here** and is **not** defined earlier on the page. But the
  line **defines it inline, where it is used**: the same sentence states plainly what it
  is — "a slim journal of confessions … recorded in a whisper-code of dots." A stranger
  DM does not need any other part of the page to run the line; the coinage resolves to a
  definition **at the point of use**. The doubt: does a term self-defined in the same
  clause satisfy "the page defines it before or where it's used"?
